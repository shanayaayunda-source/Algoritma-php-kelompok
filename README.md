# Aplikasi Algoritma PHP

Repository ini digunakan untuk pengerjaan tugas kelompok Mata Kuliah Algoritma Pertemuan 5 dan 6.

## Deskripsi

Proyek ini merupakan aplikasi sederhana berbasis PHP yang mengimplementasikan algoritma dasar dan struktur data sesuai dengan penugasan.

## Algoritma

- Bubble Sort
- Selection Sort
- Linear Search
- Binary Search
- Traversal

## Struktur Data

- Array/List
- Stack
- Queue
